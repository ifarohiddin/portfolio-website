# Portfolio — Farohiddin Isomidinov

A clean, responsive portfolio generated from your CV. Edit `index.html` content and add your own images to `assets/img`.

## Quick start
- Open `index.html` in a browser.
- Tweak colors in `assets/css/style.css`.
- Add projects or experience by duplicating the corresponding HTML blocks.
- Replace email link in the footer if needed.

## Structure
- `index.html` — main page
- `assets/css/style.css` — styles
- `assets/js/main.js` — interactions
- `assets/img/` — images (place your headshot, project screenshots)
- `assets/files/` — your CV (download button uses this)

## Notes
- The contact form is front‑end only (no backend). Hook it to a service (e.g., Formspree) or your own API to make it functional.
